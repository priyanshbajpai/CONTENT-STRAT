# Marcha System

Marcha is the content and brand layer for the Food Intelligence OS workspace.

Use this folder when creating:

- Indian sauce and food concept brands
- Marcha carousel posts
- Marcha reels or single-image posts
- editorial food concept copy
- visual prompts and text-placement guides

## Key Files

- `marcha-content-os.md` - brand positioning, audience, content pillars, research gate, realism gate.
- `marcha-copy-layout-system.md` - copy rules, carousel layout standards, image prompt base, typography rules.
- `COPY.md` - short brand copy and operating rule.
- `OUTPUT_INDEX.md` - old output library structure and delivery standard.
- `ASSETS.md` - copied asset list from the old Marcha system.

## Working Rule

For Marcha work:

1. Research first.
2. Use local food models where useful.
3. Define real food/product logic.
4. Create copy and visuals last.
5. Keep clean visuals separate from text placement guides.
