# Marcha Output Library

## Folders

- `00-marcha-system` - Marcha strategy, copy rules, layout system, and operating docs.
- `01-layout-reference-basic` - Early structural layout samples.
- `02-layout-reference-integrated` - Current preferred editorial text-placement reference.
- `03-carousel-not-ketchup` - Previous Not Ketchup carousel output.
- `04-carousel-mango-chilli-sauce` - Mango Chilli Sauce carousel output.
- `05-carousel-mango-chilli-sauce-clean` - Regenerated Mango Chilli Sauce carousel with 7 clean visuals, 7 text-placement guides, and copy separated.

## Standard For Future Outputs

Each new output should be a folder containing:

- `COPY.md` - all slide copy, caption, CTA, research notes, realism notes.
- `ASSETS.md` - list of all files inside the folder.
- `clean-visuals/` or `slides/` - output images.
- `text-placement/` or `layout-samples/` - guide images showing where text should be placed.
- `assets/` - source visuals or supporting files.

For future Marcha carousels, the preferred final delivery is 7 clean visual slides with no text, plus 7 matching placement guides and a separate copy file.
