# Research Prompts

Reusable prompts for FMCG brand and product research in this chat.

## Product Ideation

```text
Use Epicure and RecipeBERT to create FMCG product concepts for:
Category:
Hero ingredient:
Market:
Audience:
Cuisine direction:
Constraints:
Output: 10 concepts, top 3 recommendations, model signals, risks.
```

```text
Create a 5-SKU product line architecture for this FMCG idea:
[idea]
Include mass, premium, youth/fusion, regional, and limited-edition SKUs.
```

## Ingredient Research

```text
Use Epicure to find pairings, substitutes, chemistry neighbours, and cuisine shifts for:
Ingredient:
Market:
Product category:
```

```text
Make this ingredient stack cheaper while preserving flavour direction:
[ingredient stack]
Market:
Constraints:
```

## Indian Market Adaptation

```text
Take this global FMCG product idea and adapt it for the Indian market:
[idea]
Consider vegetarian acceptability, spice level, price, pack size, quick commerce, QSR, and household use.
```

```text
Create Indian fusion and global fusion variants for:
Hero ingredient:
Category:
Audience:
```

## Concept Validation

```text
Build a validation plan for this FMCG concept:
[concept]
Include tasting panel questions, concept test questions, purchase intent questions, and retail/QSR trial plan.
```

```text
Score these concepts for familiarity, novelty, launch risk, and product-market fit:
[list]
Use model signals where useful.
```

## Brand Strategy

```text
Turn this product concept into a brand strategy:
[concept]
Include brand thesis, target audience, positioning, naming directions, claims hierarchy, and packaging cues.
```

```text
Create three positioning routes for this FMCG brand:
[brand/product]
Routes: mass-market, premium, and youth/fusion.
```

```text
Create a 30-day content strategy for this FMCG product:

```

```text
Create 20 short-form video ideas for this sauce/snack/beverage brand:
[brand/product]

Audience:
```

## Retail / Pitch

```text
Create a retailer pitch for this FMCG product:
[product]
Include category problem, white space, product line, consumer use cases, margin story, and launch plan.
```

```text
Create a QSR/HoReCa pitch for this product:
[product]
Include operational use cases, menu applications, cost logic, and pilot plan.
```
