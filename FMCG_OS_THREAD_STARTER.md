# FMCG-OS Thread Starter

Use this file at the start of any new Codex thread for the FMCG-OS / Marcha project.

First read `MARCHA_SOURCE_BANK.md`. It is the master memory file for this project and contains the full creative, research, visual, copy, and output system from the original Marcha working thread.

## Brand

- Brand name: Marcha
- Direction: AI-first food content page that can evolve into a healthy Indian sauce and FMCG brand.
- Audience: Indian Gen Z foodies, healthy eating audience, gym/high-protein audience, urban quick-commerce shoppers.
- Food rules: vegetarian, egg allowed, plant-based friendly.
- Positioning: Indian pantry made global, healthy Indian sauces, premium editorial food content, FMCG product discovery.

## Creative System

- Visual style: hard-flash contemporary studio food photography with 1970s cookbook and modern pop-art commercial energy.
- Must feel realistic: every food image should look physically cookable, with accurate texture, color, gloss, viscosity, and ingredient behavior.
- Text style: text should sit inside the image's natural negative space, not inside heavy separate blocks.
- Text references: editorial menu/page layouts, fine callout lines, subtle page numbers, premium minimal typography.
- Keep AI behind the scenes.

## Brand Typography

- Display: Paquito Bold.
- Subhead: Paquito Regular.
- Body/labels: clean sans-serif such as Inter, DM Sans, Helvetica, or Canva Sans.

## Brand Colors

- Deep Teal: `#0F6F78`
- Cream: `#FFF4D8`
- Chilli Red: `#D7382F`
- Turmeric Yellow: `#F2B544`
- Ink Black: `#17120F`

## Format Rules

- Carousel: 7 slides, `1080 x 1350`, clean visuals with no text plus matching text-placement guide images.
- Single feed image: `1080 x 1350`.
- Reels/stories: `1080 x 1920`.
- Every output folder must include:
  - `clean-visuals/`
  - `text-placement/`
  - `COPY.md`
  - `ASSETS.md`
  - contact sheets for review

## Required Workflow

1. Research current food, FMCG, social, and India/Gen Z trends before creating concepts.
2. Build the food concept and copy together.
3. Generate clean visuals first.
4. Generate text-placement guides separately.
5. Validate aspect ratio and pixel dimensions.
6. Save everything into a fresh numbered output folder.
