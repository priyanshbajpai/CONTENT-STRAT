# Brand System: Typography

## Primary Font Family

Use **Paquito** as the signature display/editorial font for the AI food page.

Local font path:

```text
work/brand-assets/fonts/Paquito_Complete/
```

Available local styles:

- `Paquito-Regular`
- `Paquito-Medium`
- `Paquito-Bold`
- `Paquito-Variable`

## Usage

### Carousel Covers

Use `Paquito-Bold` or `Paquito-Variable` at weight `650-700`.

Examples:

- `Not Ketchup.`
- `Future Chutney.`
- `Indian sauces that should exist.`
- `Makhani hummus should exist.`

### Subheads

Use `Paquito-Regular` or `Paquito-Medium`.

Examples:

- `AI-generated Indian food concepts.`
- `Made with India-available ingredients.`
- `Would you try this?`

### Body Copy

Pair Paquito with a clean sans serif such as:

- Inter
- DM Sans
- Helvetica
- Neue Haas Grotesk-style sans serif

## Visual Direction

Paquito should make the page feel:

- editorial
- premium
- food-magazine-like
- slightly vintage
- modern Indian-global

## Color Pairing

Recommended palette:

- Deep teal: `#0F6F78`
- Cream: `#FFF4D8`
- Chilli red: `#D7382F`
- Optional black: `#17120F`

## Rules

- Use Paquito for big expressive words.
- Do not use more than two font families in one post.
- Keep carousel covers simple: one big Paquito headline, one small subtitle, one strong AI food/product visual.
- Do not commit font binaries to public GitHub unless license/distribution is explicitly reviewed.

## AI Prompt Rule

When generating visuals, ask for typography in this direction:

```text
Use Paquito-style high-contrast editorial serif typography: large elegant letters, premium food magazine feel, cream text on deep teal or chilli red backgrounds.
```

If a tool cannot use local fonts directly, generate the image without baked-in text and add Paquito text later in Canva, Photoshop, Figma, or an editing tool.
